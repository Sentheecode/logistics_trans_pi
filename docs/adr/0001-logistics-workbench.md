# ADR 0001：物流单屏工作台与模拟边界

状态：已实现于 C++ 实验分支。最新入口和验收证据见 [架构](../../ARCHITECTURE.md) 与 [验证记录](../../cpp-runtime/VALIDATION.md)。

- Qt Widgets 使用浅色页签及 PLC 上下文。运行页并列呈现全部站位，点选只切换工位详情。采集、点表、日志和事件按详情工位隔离。
- 外装右俯视图使用静态机械臂示意。三车仅在 140 运行表表示本轮顺序和阶段，每车完成仅属于本工位本轮。
- 资料状态与采集证据各自呈现。登记的点表、缺失的点表、候选归属和模板内容重合均保留原有解释。140 点表从程序同目录的独立 SQLite 读取，与采集库分开；文件不可读时工作台失败。150 与 160 仍未导入。
- Windows GUI 启动器独立启动工作台和模拟采集器，并把进程输出保存到独立目录。采集续跑、CLI、归档及 MCP 的 stdio 保持独立。

使用两种窗口尺寸、排序分组、相邻工位和仪表工位测试。自动化验证覆盖 Linux Qt 及 Windows 解压烟测。Windows 工控机的界面、缩放和长时性能另行验收。
