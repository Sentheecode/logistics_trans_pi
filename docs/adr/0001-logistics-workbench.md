# ADR 0001：物流单屏工作台与模拟边界

状态：已实现于 C++ 实验分支。最新入口和验收证据见 [架构](../../ARCHITECTURE.md) 与 [验证记录](../../cpp-runtime/VALIDATION.md)。

- Qt Widgets / C++17 主屏是一张连续工位工作面：工位、名称、当前作业、数据来源。模拟只在已绑定工位的行内展开，三车阶段只反映当前帧，不推定前序已经完成。未绑定的工位留短空态。长日志和快照字段在采集页或日志页。日志视口只容纳完整行，不靠缩小正文字号消掉半行。点表、接口和完整日志在工厂选择器上方的页签中打开。
- 工厂 → PLC 决定浏览范围。分拣和排序区只是 PLC 菜单的分组标题。一台 PLC 包含多个工位。线体与 PLC 是同一配置对象，界面不保留线体或业务模式下拉。页签是运行、日志、采集、点表、接口。采集目标由独立进程固定，目录交互只改变浏览范围。
- SPS 示例单把当前帧的活动料车、已完成车数和取料工位投影到文字及共用通道。固定工位各有货架与机械臂示意。料车不归属于某个固定工位，画面无真实坐标、方向、调度或实际回执。
- 排序区四个 PLC 各显示自己的已命名工位，暂无排序业务流，也不借用工位 140。候选点表登记是独立的文档可用性，不是采集绑定或已装入配置；运行页只写「已登记点表 · 未接入」，「工位对应待确认」留在点表审计。没有工位的 PLC 才显示未配置。手动／自动是采集模式，和分拣／排序区业务模式分离。未绑定模拟采集的 PLC 不显示工位 140 的标题、记录或推进说明。手动单步使用既有模拟控制边界。
- 钱塘二厂的可见范围按 PLC 命名（外装、仪表一、仪表二、排序区一至四）。“SPS（立库）”和“示例线 A/B”只是早期示例标签，不再作为业务模式或导航。北岸、南湾示例厂仍保留示例名称，用来验证未配置范围。采集归属在顶栏保持为外装，和当前预览的 PLC 分开。
- 以可信帧为证据。断链、过期、坏质量和无帧时，进度和目标显示未知。保持旧库迁移、只读诊断、审计和采集生命周期独立。

验收使用匿名合成数据。用 1280×800 与 1100×650 检查主屏，回归选站同步、数据与操作范围、手自动、坏质量和恢复；运行 Qt、核心及旧 Node 测试。真实生产分拣、工位协议、现场布置和 Windows 目标环境仍需独立验收。
