# ADR 0001：物流单屏工作台与模拟边界

状态：已实现于 C++ 实验分支。最新入口和验收证据见 [架构](../../ARCHITECTURE.md) 与 [验证记录](../../cpp-runtime/VALIDATION.md)。

- Qt Widgets / C++17 主屏集中阶段、订单示例、拓扑、采集质量、告警、近期记录与固定操作带。点表、接口和完整日志通过诊断弹窗打开。
- 工厂 → 业务模式 → 线体 → 工位决定浏览范围。PLC 由配置关联，可关联多个工位。采集目标由独立进程固定，目录和拓扑交互只改变浏览范围。
- SPS 示例单把当前帧的活动料车、已完成车数和取料工位投影到文字及共用通道。固定工位各有货架与机械臂示意。料车不归属于某个固定工位，画面无真实坐标、方向、调度或实际回执。
- 排序区和未绑定工位提供配置、空态与示意，暂无排序业务流。手动／自动是采集模式，和 SPS／排序区业务模式分离。手动单步使用既有模拟控制边界。
- 以可信帧为证据。断链、过期、坏质量和无帧时，进度和目标显示未知。保持旧库迁移、只读诊断、审计和采集生命周期独立。

验收使用匿名合成数据。用 1280×800 与 1100×650 检查主屏，回归选站同步、数据与操作范围、手自动、坏质量和恢复；运行当前 Qt、C++ 核心和只读 MCP 测试。真实生产分拣、工位协议、现场布置和 Windows 目标环境仍需独立验收。

跨工位浏览按工位校验数据及模拟命令。同一 PLC 的归属关系只用于导航。参考资料中的候选字段只进入资料核对说明，新任务或回执接入需提供独立证据。
