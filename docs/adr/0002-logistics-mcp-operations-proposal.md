# ADR 0002：物流上位机 MCP 运维提案

状态：**提案，未实现，不在本轮开发**。当前没有创建或部署 MCP 进程、网关、工具或发布通道。

每台物流上位机拟运行独立的低权限运维进程，与采集、HMI、Pi 的生命周期隔离。企业内网网关作为访问入口，工位不对外开放 MCP 端口。访问应在网关与工位分别校验权限、工位范围和操作预算。

第一阶段只考虑本地只读版本、心跳、告警及按工位查日志。固定查询、时间窗、行数及速率上限，响应最小化并脱敏。日志文本一律视为数据，不能触发动作。用合成记录验证跨工位拒绝、身份校验、超限与脱敏、读取失效，以及停止诊断后采集无影响。

后续若获授权，只允许白名单配置的差异预览，应用前由有权限的人确认具体差异与版本。代码变更走仓库评审。软件更新走独立可信签名发布链路，在维护窗口试点；验签失败拒绝，验证回退与工位数据保护后才扩大覆盖。应测试错误签名／版本、变更审计、维护窗口强制、试点失败回退及数据保留。

设计不提供 shell、任意文件读写、PLC 写点、设备控制或绕过联锁。进入开发前确认权限模型、威胁模型和隔离验收，进入发布前完成演练。此提案仅适用物流项目。
